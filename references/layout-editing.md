# 排版偏好与模板编辑

## 询问并保存偏好

与 `user-experience.md` 的一轮启动合并，不单独重复问一遍背景和资料。只要求选择方向，具体参数可随预览细调。

先读取项目约定及参考样例，避免重新询问已确定的版式。新项目可一次询问：

> 排版希望沿用参考讲义、使用默认模板，还是自定义？自定义时可以告诉我颜色、字体、字号、行距、首行缩进、页边距，以及偏紧凑还是偏宽松；不确定的项目可以先用默认值看预览。

将 `assets/style-preferences.md` 复制为项目的 `排版偏好.md`，用用户回答更新。状态分为“默认待预览”“用户已指定”“用户已确认”，不能把默认值记录为用户确认。后续用户可以直接编辑文件，也可自然语言修改某一项。

读取不到用户答复时，可在合理等待后用明确说明的默认值制作预览；若用户要求必须等待其选择，则不执行依赖该选择的改版。用户只要求修改skill时，建立此流程，不立即向其询问某门课程的偏好。

## 参数到模板的对应

`assets/lecture-template.tex` 是可独立编译的模板样页，参数集中在顶部，可复制为新项目主源。正文中的样例用于查看版式，建立正式讲义时替换，不能当作该课程已经完成的内容。

| 偏好 | LaTeX参数或位置 |
|---|---|
| 学科与封面标题 | `\LectureTitle` |
| 主色、浅底、边框 | `\LectureMainColor`、`\LectureBackColor`、`\LectureBorderColor` |
| 中文、西文、代码字体 | `\LectureCJKFont`、`\LectureLatinFont`、`\LectureCodeFont` |
| 正文字号与行距 | `\LectureBodySize`、`\LectureBodyBaseline`、`\LectureLineSpread` |
| 首行缩进与段距 | `\LectureIndent`、`\LectureParagraphSkip` |
| 四边页边距 | `\LectureLeftMargin`等四项 |
| 标题和代码字号 | `\LectureSectionSize`、`\LectureSubsectionSize`、`\LectureCodeSize` |
| 目录层级与书签 | `\LectureTOCDepth`、`\LectureBookmarkDepth` |
| 框内边距、边框厚度 | `\LectureBoxPadding`、`\LectureBoxRule` |
| 封面字号与位置 | `\LectureCoverSize`、`\LectureCoverOffset` |

字号数值以pt解释；中文小四对应12pt。模板的正文基线为字号的1.2倍，再乘行距系数；例如12pt、14.4pt基线和1.22行距。修改字号时相应更新基线及必要的标题/代码字号，不把其相乘后的数值误记为1.22pt。

## 编辑与预览

1. 将偏好写入项目文件，并映射到模板或已有源文件的集中样式区。用户的新选择覆盖默认值。
2. 首次定制先生成短预览，包含封面、正文、公式、表格、信息框和适用时的代码。允许用户自然语言继续修改，也允许直接编辑参数。
3. 检查编译、字体可用性、可读性、文字与背景的对比以及分页。缺少指定字体时说明替代字体，预览用替代字体不等于最终字体达标。
4. 用户确认或已授权采用后，将参数同步到主源和编写约定，保留用户已修改的其他项。复制模板只在初始化时进行，不用默认模板覆盖已有正文。
5. 后续版式变化应用于累计讲义并检查全部受影响页面；不通过更改字号或行距掩盖内容不足。

保持信息框浅底、细边且允许跨页；长推导置于正文。短代码可保持完整，长代码按功能拆分。采用三线表，保证图表不裁切、标题与下文相接。用户要求其他风格时按其选择适配。

## 导航与阅读版

LaTeX模板使用 `\termdef{mean}{算术平均数}` 创建术语目标，`\termref{mean}{算术平均数}` 回指；`\exercise{mean-1}{1.1}` 和 `\answer{mean-1}{1.1}` 创建题目与答案的双向链接。目标ID保持唯一且稳定。术语索引只收录已有定义，避免出现无法点击的空条目。

HTML阅读版由 `build_reader.py` 用结构化正文数据生成，无须安装Quarto。它提供章目录、全书搜索、答案展开、复制代码、局部修改反馈及偏好导出。例子支持普通文本/Unicode公式；复杂数学排版需要另行适配，不能默认把HTML当作主PDF的等价版本。
